# 安靜存錢筒

國小班級用的互動網頁：全班安靜時累積金幣，吵鬧時扣除金幣，一起存到班級共同目標。

**使用網址：** https://335588yyyti.github.io/quiet-piggy-bank/

## 功能

- 用裝置麥克風即時偵測教室音量（0～100 的相對數值，不是精準分貝）
- 連續安靜 10 秒加 1 枚，連續吵鬧 3 秒扣 1 枚，最低 0 枚（秒數與枚數都可調整）
- 咳嗽、東西掉落等短暫聲音不會扣幣
- 開始／暫停／繼續；切換到其他分頁會自動暫停
- 手動加幣、扣幣、歸零（需確認）與復原上一步
- 環境音校準、班級共同目標與達標慶祝、投影模式
- 金幣與設定自動儲存在這個瀏覽器

## 隱私

聲音只在裝置本機即時分析，不錄音、不上傳。頁面不播放任何聲音。

## 使用需求

- 需要有麥克風的電腦、平板或手機
- 請用 Chrome、Edge 或 Safari 直接開啟網址（不要在 LINE、Facebook 等 App 內開啟）
